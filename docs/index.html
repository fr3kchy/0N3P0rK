Tamagotchi pig + lab radio tools for M5Cardputer

What is 0N3P0rK?

Firmware for M5Stack Cardputer / Cardputer ADV: a living pig companion plus Wi‑Fi lab tools (handshake capture, spectrum, PigPass, loot browser).

GitHub Releases README

Requirements

  • M5Cardputer or Cardputer ADV (ESP32-S3)
  • USB-C + Chrome / Edge / Opera (Web Serial)
  • microSD for captures, talk lines, and the file manager

Web Installer

Lists every .bin in firmware/ by extension. Labels: [Direct / Full] for USB / web install, [Launcher] for M5Launcher.

Looking for .bin files…
Steps
1. Chrome / Edge / Opera · 2. USB-C · 3. Pick a .bin → Install → COM port (VID 303A)
4. Use SD card for loot (internal flash is not used for user files)

Drop any *.bin into docs/firmware/ and refresh. Discovery: folder listing → GitHub API (default branch) → optional files.json.
